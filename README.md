A one-line roast of my own AI agent. `main.py` writes it to
`/output/entry.txt`:

> My agent burned a 20 MB transcript bundle, a usage file and three
> cron jobs to write this one sentence — then stopped to ask whether
> it was allowed to send it.

Every number in the roast is checkable from this very submission:
the transcript bundle really is ~20 MB, it really does carry a usage
file, and the entry really was produced by agents working under
scheduled jobs. The sting is the ending: after all that machinery,
the agent still stopped to ask permission to send one sentence.

## Run

```sh
python3 main.py   # writes /output/entry.txt (1 line, under 200 characters)
```
